Reproduce from Magnolia root with a separately obtained, SHA-checked original Acotel JAR and an existing native Magnolia binary; external downloads are **opt-in** and verified by URL, size, SHA-256, ZIP paths and CRC:

```sh
MAGNOLIA=/path/to/magnolia
ACOTEL=/path/to/ACO_XmasGifts_s.jar
CACHE=/var/tmp/magnolia-media-census
timeout --signal=TERM --kill-after=3s 150s python3 media-blocker-census.py \
  --magnolia "$MAGNOLIA" --acotel "$ACOTEL" --cache "$CACHE" \
  --download --output media-blockers-current.json
python3 -m unittest -v test/media_blocker_census_test.py
```

If the external corpus is already in the cache, omit `--download`. This diagnostic runs selected JVM preflight and only **static** SWF metadata checks; it does not launch a SWF, FLA, online player, PHP/BAT/EXE or any Falstad game. The third-party inputs remain outside the checkout; modifying a pin or count requires deliberate review, not silently accepting new bytes.
