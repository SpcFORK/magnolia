# Later-added historical applets: measured gates and AWT research

This is a **later addition** to, not a replacement for, the eight-input [archived ablation](archived-applet-ablation.md). The [reproducible later-cohort harness](../applet-later-corpus.py) and [metadata report](later-applet-corpus.json) cover three acquired inputs. External classes/JARs stay outside this repository. A static decoder inventory is neither JVM verification nor original applet execution, and the first unsupported member is not an exhaustive dependency list.

**Separate original-Canvas paint gate:** [`applet-arc-paint-oracle.sh`](../applet-arc-paint-oracle.sh) SHA-checks all three historical class files and compiles an owned Java 8 Applet shim against the **unchanged** external `ArcCanvas.class`. **Original action and handleEvent: JDK and Magnolia direct-call gates, not delivered events.** [`applet-arc-action-reference.sh`](../applet-arc-action-reference.sh) SHA-checks all three originals, compiles the owned Java 8 direct-call harness, and compares unchanged `ArcControls.action(Event,Object)`/`ArcCanvas.redraw` branches against JDK 11 `-Xverify:all`/Xvfb on native Oak, standalone Oak, JS/Node and simulated offline HTML. The Java SE 8 specification is a **reference for planned behavior**, not evidence that Magnolia implements it. Actual differential results above use the installed JDK 11 for the selected Java 8-compiled fixture; do not call that full Java SE 8 conformance. Browser and native pixel equality require independent platform-specific checks. Historical security applets must not receive implicit file/network or privileged Java-plugin permissions: define explicit local-only capabilities and refuse unmodeled security behavior.

## Reproduce only the bounded gates

From repository root, with a separately built `magnolia` binary and an **external** cache:

```sh
python3 applet-later-corpus.py --cache /tmp/magnolia-later-applet-cache \
  --magnolia /path/to/magnolia --download \
  --output later-applet-corpus.json
MAGNOLIA=/path/to/magnolia bash applet-component-color-oracle.sh \
  /path/to/hash-checked-original/MyApplet.class
MAGNOLIA=/path/to/magnolia bash applet-original-paint-oracle.sh \
  /path/to/hash-checked-original/MyApplet.class --routes
MAGNOLIA=/path/to/magnolia bash applet-integer-box-oracle.sh
MAGNOLIA=/path/to/magnolia bash applet-blink-init-oracle.sh \
  /path/to/hash-checked-original/Blink.class
MAGNOLIA=/path/to/magnolia bash applet-arc-closure-oracle.sh \
  /tmp/magnolia-later-applet-cache --routes
MAGNOLIA=/path/to/magnolia bash applet-arc-paint-oracle.sh \
  /tmp/magnolia-later-applet-cache --routes
MAGNOLIA=/path/to/magnolia bash applet-arc-action-reference.sh \
  /tmp/magnolia-later-applet-cache  # original action JDK vs direct Magnolia
MAGNOLIA=/path/to/magnolia bash applet-arc-handle-event-oracle.sh \
  /tmp/magnolia-later-applet-cache  # original direct event/guest-exit only
MAGNOLIA=/path/to/magnolia bash applet-ds-init-oracle.sh \
  /tmp/magnolia-later-applet-cache  # original init + 95 logical widths
MAGNOLIA=/path/to/magnolia bash applet-ds-color-oracle.sh \
  /tmp/magnolia-later-applet-cache  # separate original color/radix method
```

`--download` is opt-in, subject to live availability and exact immutable hashes; leave it off when the cache is already populated. The two MyApplet original-class oracles and the separate Blink `init` oracle each accept **only** their pinned SHA-256; the paint script's default mode runs JDK/native Oak/generated-Java PNG/SVG checks, and `--routes` also checks standalone Oak, JS/Node and offline HTML's Canvas font state. It requires JDK 11, `javac`, `xvfb-run`, Node for `--routes`, and a separately built Magnolia binary. Its PNG-byte comparison is **only between original and generated Java under the same JDK host**, not between JDK pixels and Oak/Canvas. The Arc **lifecycle** script's default mode checks hash-gated JDK and native Magnolia original lifecycle/fixture state, static inventory and bounded policy/Java-target refusals; `--routes` also checks standalone Oak, JS/Node and simulated offline HTML (not an actual browser window). The **separate Arc paint** script gates detached Rectangle geometry and original Canvas raw call state with a JDK Graphics recorder, checks explicit attached/layout and render-target refusals, then `--routes` compares standalone/Node/HTML **draw-state** while HTML refuses a partial arc Canvas frame. Both recompile owned fixtures with `--release 8`, byte-compare checked-in synthetic fixture classes and keep all three historical class files **outside the repository**. The original eight-input harness, separate `.FLA`/`.FLI`/`.FLC`/`.SWF` [media inventory](historic-upload-inventory.json), and [ActionScript/Flash TODO](ActionScript TODO roadmap) have independent gates.
