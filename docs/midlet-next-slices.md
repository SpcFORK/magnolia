## Independently checked, deliberately narrow behavior

All positive fixtures were compiled **once against pinned real MicroEmulator 2.0.4**, then the **identical class bytes** were run separately in MicroEmulator/JDK 11 `-Xverify:all` and Magnolia's native, selected MIDlet route. Reference and unchanged-game JARs stay **outside the checkout**; the owned fixtures, *not* the original Acotel classes, are the native programs in this table. Each oracle rechecks the SHA-256/size pins before launching a bounded reference child, checks its own bytes against checked-in fixture classfiles, and requires an explicit native exit **0**. Runtime refusals emit no partial **CLI** trace; unlike malformed JAR/class preflight refusals, they are not asserted to have been statically detectable.

### Reproduce the new gates from the repository root

With pinned external `microemulator-2.0.4.jar`, unchanged `ACO_XmasGifts_s.jar`, and a locally built Magnolia executable, run **sequentially** to avoid reference/VM CPU contention. Each command exits `0` only for its stated profile; no command reads the archived JAD URL.

```sh
for kind in random command thread canvas-size blit; do
  timeout --signal=TERM --kill-after=2s 80s python3 "midlet-${kind}-oracle.py" \
    --magnolia /path/to/magnolia \
    --microemu /path/to/microemulator-2.0.4.jar \
    --original-jar /path/to/ACO_XmasGifts_s.jar \
    --output "midlet-${kind}-reference.json"
done
# Separate opt-in one-frame selected Canvas oracle (not Acotel execution):
timeout --signal=TERM --kill-after=3s 100s python3 midlet-paint-oracle.py \
  --magnolia /path/to/magnolia \
  --microemu /path/to/microemulator-2.0.4.jar \
  --original-jar /path/to/ACO_XmasGifts_s.jar \
  --output midlet-paint-reference.json
python3 -m unittest -v test/midlet_paint_oracle_test.py
# Separate, fixture-only two-frame service oracle (not original gameplay):
timeout --signal=TERM --kill-after=3s 150s python3 midlet-service-oracle.py \
  --magnolia /path/to/magnolia \
  --microemu /path/to/microemulator-2.0.4.jar \
  --original-jar /path/to/ACO_XmasGifts_s.jar \
  --output midlet-service-reference.json
python3 -m unittest -v test/midlet_service_oracle_test.py
```

These tests, the reference-frame probe and the **not-yet-closed** acceptance plan are linked from [`docs/completion-pass.md`](completion-pass.md), [`docs/midlet-finite-runtime.md`](midlet-finite-runtime.md) and [the JVM TODO roadmap](JVM TODO roadmap).
