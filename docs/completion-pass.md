## Reusable acceptance contract — run it once per artifact/profile

For each candidate, record a case manifest with: exact artifact/version and SHA-256; rights/redistribution decision; classpath/descriptor/assets; a pinned **independent** real reference; host/profile and explicitly granted capabilities; deterministic actions and bounded wall/VM/memory/frames/output budgets; expected constructor/lifecycle/state, pixels, audio and input/termination traces when intrinsic to its purpose; valid and malformed tests; same-layout edits/round-trip rules only if it is a writer. The executable gate follows this strict order:

1. **Admit:** enforce byte hashes, archive/format/class-version rules and local-only permissions **before** any output, network or external process. Name what is absent rather than silently substituting a different program, version or runtime.
2. **Link and preflight:** resolve *all* reachable methods/resources/callbacks and their verifier/capability envelope. Unknown APIs, wrong interfaces, malformed input or exceeded budgets must refuse before partial output/artifacts; a static decoder count is only a diagnostic.
3. **Reference:** independently run the **unchanged original** with its real runtime/device and capture purpose-specific output. A Java SE applet reference cannot stand in for Java ME; a SWF5 AVM1 movie cannot be certified by Flash 2 Java; AS3/ABC is a separate AVM2 reference.
4. **Magnolia:** run the **same unchanged original** in Magnolia's declared host, not merely an owned fixture or a separate online player. Record actual start, state transitions, input and pixels/audio/exported bytes; compare to the reference within explicitly justified timing/renderer tolerances.
5. **Negative and route matrix:** run corrupt/unauthorized/out-of-profile cases; verify pre-output refusal, timeout/budget exits and exact restoration for writers. Run each claimed native/standalone Oak/JS/offline HTML/generated-Java route with captured **exit 0**. A timeout, a class-load without initialization or a first-blocker move is a non-pass.
6. **Close only the matching entry/cohort** when its original purpose and all declared target routes pass; the remaining 48 unchecked entries stay open until their written acceptance is actually met. Create the requested successor TODO **only after** both current TODOs and the ledger's acceptance are complete.

This is the only useful meaning of **“one pass”**: one repeatable, versioned integration harness and topologically ordered gates, not one broad unchecked claim or a promise that many distinct runtimes can be implemented in a single coding change.
