## Procedure and claims

The original program/media bytes must remain hash-pinned and outside the source delivery unless rights are resolved. For each selected artifact: check format, archive/inner-file/hash and dependencies; use a real independently version-pinned reference for **end-to-end intended behavior**; run the original bytecode/program in Magnolia's explicitly bounded target; compare lifecycle and deterministic state, frames/pixels, audio and input when they are integral; prove unsupported paths fail before effects/output, and finish a bounded suite with a captured **exit 0**. `.fla` source is not `.swf`, Flash 2 is not SWF5 AVM1 or AS3 AVM2, and `.class`/JAR is not Java ME MIDP without its own host. A timed-out run, static purpose inference, source inventory, JDK `Class.forName(..., false, ...)`, or one selected method does not close a functional gate.

Current [cross-media first-barrier/static census](media-blocker-census.md) is diagnostic, not an additive bug total; [static media purpose and SDK provenance](historic-media-purpose.md) have separate reference-only and finite-writer gates. Scoped execution includes [Fliplay/AWT](applet.md), [finite MIDlet fixtures](midlet-finite-runtime.md), [opt-in one-frame owned Canvas paint](midlet-paint-reference.md), [historic JVM/SWF corpus](archived-applet-ablation.md), [No Hats reference-only JDK splash](nohats-current-reference.json), and [isolated AS3JS Node source compiler](as3js-baseline.md). The remaining **21 JVM and 24 ActionScript** unchecked entries stay open. The earlier JVM round explicitly excluded `Math.round`; this later [bounded, independently JDK-oracled primitive slice](jvm-math-round-preflight.md) now covers its **exact `(F)I` and `(D)J` static overloads**, not Fourier execution or completion of any broader JVM entry.
