# Original SWF5 sprite-11 AVM1 preloader — direct action-body gate

**Checkpoint: executable, but deliberately not SWF playback.** The opt-in Oak [`lib/avm1-preloader.oak`](../lib/avm1-preloader.oak) interprets **the original binary ActionRecords**, not decoded JSON, from **both** `DoAction` tags in sprite 11 of the user's unchanged `asdf.swf.txt`. A separately written [Python oracle](../avm1-preloader-oracle.py) pins the **entire** 2,418,588-byte FWS5 upload (SHA-256 `2bde4d96b5b6695f8dd81afe005080c2bc6b9a14545f7cc8f35f49c71ac43cbc`), independently walks all **7,394** SWF tag headers, verifies sprite 11's **three** frames, locates the `loaded` frame label at zero-based **frame 2**, independently checks ActionRecord structure, then passes the exact original bytes to the Magnolia CLI. The third-party SWF and extracted action binaries stay outside the repository. This direct gate is **not an independent Flash-player comparison**; the expected values/events are calculated separately in Python from the fixed original action listing and the [Adobe SWF action definitions](https://open-flash.github.io/mirrors/swf-spec-19.pdf).

| Original sprite-11 action tag | SWF byte offset and digest of action payload | Direct verified effect |
| --- | --- | --- |
| Frame 0, 201 bytes, 33 records including `End` | Offset **1966**; `64df021d81c7f7e819cee52a859a66de2ee180656749457e4e17f44abe3f2b22` | `_root.stop()`; read `_root.getBytesLoaded()` and `getBytesTotal()` from a **fixed synthetic host snapshot**; assign `PercentLoaded = loaded / total * 100`. At 100%, dispatch `GotoLabel("loaded")` on the current sprite; otherwise assign `bar._xscale = PercentLoaded` and branch over that label. `Equals2`, both `Not`s, `If` and `Jump` execute rather than being decoded only. |
| Frame 1, 7 bytes, 3 records including `End` | Offset **2226**; `3613fd4cafbbadbc494ac2f7d56985d07723857c608abc02777618d7d8e89464` | A **separate direct call** emits `GotoFrame(0)` then `Play` for the current sprite; this does **not** schedule another frame or render a scene. |

The original frame-0 body passed **seven distinct host snapshots** (zero, quarter, 24.5%, 37.5%, near-complete, complete, and 1/1 complete); its exact event order, values, branch, stack depth and **per-action byte offsets** match the independent calculation. The completed and incomplete paths together visit **all 33 frame-0 records**; the separate frame-1 calls visit its **three** records. For example, **49/200** writes `PercentLoaded=24.5` and `bar._xscale=24.5`, whereas **100/100** writes `PercentLoaded=100`, emits `GotoLabel("loaded")`, and does **not** write `_xscale`. The frame-1 body passed two additional direct calls, including one at a complete snapshot **only as an isolated action-body test**; a real player would need to decide whether it would schedule that frame at all. The bounded oracle exited **0**, with **24 one-line pre-output refusals** for changed/unknown actions, invalid branch/pool/Push data, altered host calls, stack underflow, a synthetic self-loop (64-action budget), mismatched host counts, oversized bodies and unsupported options. It also checks that a one-byte-corrupted full SWF fails its source hash **before extracting/executing anything**. [Exact cases, traces and refusal messages](avm1-preloader-original.json).

**Supported profile and limits:** one 1–512-byte direct `DoAction` body per call; at most **64** decoded records, **64** executed actions and **16** stack values; ASCII strings ≤64 bytes and one first-record constant pool ≤16 entries. The only admitted Push numbers are positive-zero doubles and nonnegative bounded int32s. Numeric `Equals2` and Boolean `Not`/`If` cover just the original operand types; other AVM1 conversions and exceptional IEEE values are refused. The only host objects are the virtual `_root` (three named zero-argument methods) and virtual `bar` (`_xscale` write), with integer `0 ≤ loaded ≤ total ≤ 1,000,000` and total ≥1. Variable scope and frame navigation are **recorded direct effects**, not a sprite/display scheduler. Unsupported opcode/operand/branch structure is checked across the whole body **before** the interpreter emits a result, even in an untaken branch; a later dynamic refusal also emits no partial guest event trace. The CLI's direct input is unpinned; **only the Python oracle** binds it to the verified SWF.

Reproduce with the supplied upload outside the checkout and a freshly built native binary:

```bash
mkdir -p /var/tmp/magnolia-avm1-built
go build -o /var/tmp/magnolia-avm1-built/magnolia .
python3 avm1-preloader-oracle.py \
  --magnolia /var/tmp/magnolia-avm1-built/magnolia \
  --swf /home/user/uploads/asdf.swf.txt \
  --output avm1-preloader-original.json
```

**Still blocked in this direct-action gate:** it performs no automatic sprite placement or scheduling, no measured real loading process, no shape/text pixels, MP3 decode/playback, input or browser host, no Flash-compatible independent player, no generic AVM1 object/coercion/prototype/exception model, and no `.as` compiler/AVM2. A **separate later [whole-SWF first-frame prefix](avm1-swf-timeline-prefix.md)** now reads the original SWF container and enters only root frame 0 and its nested preloader frame-0 action; it does **not** retroactively make the direct-action test or the full movie a player. This verifies a **single bounded original-program preloader behavior slice** (including two action bodies), **not** the 2,140-frame uploaded movie's intended full behavior and **not** any fully accepted broad ActionScript checklist item. The standing **21 JVM / 24 ActionScript unchecked entries** and unknown non-additive blocker total are unchanged. The earlier [purpose report](historic-media-purpose.md) remains a static diagnostic; this separately checked direct action-body execution does not retroactively make its structural fields an execution oracle.
